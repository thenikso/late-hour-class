# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, criticise code and not people, and remember that many contributors are students sending their first pull request. Harassment, insults and sharing anyone's personal data are not welcome.

To report a problem, contact the maintainer privately through the email on their GitHub profile. Reports are kept confidential. The maintainer may remove comments, close issues or block anyone who doesn't follow this code.
